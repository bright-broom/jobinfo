# JobInfo

職務経歴書を表示するNext.jsアプリケーション

## プロジェクト構造

```
src/
├── app/
│   ├── components/
│   │   ├── SectionHeader.jsx    # 共通のセクションヘッダーコンポーネント
│   │   ├── CompanyInfo.jsx      # 会社情報セクション
│   │   ├── JobSection.jsx       # 職務概要と業務内容
│   │   ├── SkillsSection.jsx    # スキルセクション
│   │   └── ContentSection.jsx   # 汎用コンテンツセクション
│   ├── data/
│   │   └── career-data.js       # 職務経歴データ
│   ├── globals.css              # グローバルスタイル
│   ├── layout.js               # アプリケーションレイアウト
│   └── page.jsx                # メインページコンポーネント
```

## 技術スタック

- Next.js 14.0.4
- React 18.3.1
- TailwindCSS 3.3.0
- FontAwesome/React Icons

## 実装の特徴

### コンポーネント設計

- **アトミックデザイン**: 再利用可能な小さなコンポーネントから構築
- **責務の分離**: 各コンポーネントが単一の責務を持つように設計
- **型安全性**: PropTypesによる型チェックの実装（今後の課題）

### データ管理

- **データとUIの分離**: すべてのコンテンツデータを`career-data.js`に集約
- **保守性**: データ更新が容易な構造設計
- **拡張性**: 多言語対応やデータ形式の変更に対応しやすい構造

### パフォーマンスとアクセシビリティ

- **レスポンシブデザイン**: モバイルファーストのアプローチ
- **アクセシビリティ対応**: セマンティックなHTML構造とARIAラベルの実装
- **最適化**: 適切なコンポーネント分割とメモ化の準備
